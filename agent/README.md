# PC Control Agent

Агент, устанавливаемый на клиентский ПК для подключения к серверу и взаимодействия с Telegram-ботом.

## Возможности
- Автоматический поиск установленных игр и программ
- Получение информации о системе
- Получение и выполнение команд от сервера
- WebSocket-соединение с серверной частью

## Установка
```bash
pip install pc-control-agent
```

## Использование
```bash
pc-agent -f config.json
```

## Конфигурация
Файл `config.json` должен содержать:
```json
{
  "server_url": "ws://example.com:33444"
}
